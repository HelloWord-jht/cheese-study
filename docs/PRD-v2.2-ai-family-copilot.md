# 小满的小世界 V2.2：AI 家庭共学助手 PRD

> 状态：P0 已完成
> 日期：2026-08-21
> 目标终端：手机、平板优先
> 核心用户：三岁儿童的家长及家庭陪伴者

## 1. 背景与判断

V2.1 已有 45 个语文、数学、英语审核活动，DeepSeek 能根据兴趣和近期表现安排每日三个任务，并生成家长侧选题解释。下一阶段需要把 AI 从“后台排课器”升级为“家长共学助手”。

本产品实际使用方式以成人陪伴为主。家长具备独立判断能力，希望获得开放讨论、内容延展、亲子活动设计、观察解读和课程调整建议，而不是只接收固定模板答案。

同时必须区分两个完全不同的 AI 场景：

1. **儿童活动编排**：儿童直接接触，继续只选择人工审核活动，不允许模型临时改答案。
2. **家长 AI 助手**：只在长按进入的家长中心出现，可进行开放问答，不增加本地内容白名单或额外审查层；模型供应商自身的安全策略仍然生效。

## 2. 产品目标

- 家长可以围绕孩子近期表现进行连续问答。
- 家长可以选择 DeepSeek 或 GPT，并看见当前具体模型与连接状态。
- AI 可以读取匿名、结构化的近期学习摘要，但默认不读取昵称，也不上传语音、照片或完整设备数据。
- 家长可以一键关闭学习上下文，进行普通育儿或教育讨论。
- AI 回答允许更完整、更成人化的表达，不强制套用幼儿话术。
- 为未来接入更多模型、语音、图片理解和工具调用保留统一接口。
- 试玩结束后，可以一键清空当前设备的进度、计划和 AI 对话。

## 3. 非目标

- 不把开放 AI 问答放进儿童首页或活动页。
- 不让模型直接修改审核题库中的正确答案和活动结构。
- 不在本版本实现账号体系、云端聊天记录或跨设备数据库同步。
- 不承诺 AI 建议替代医疗、心理、语言发育或教育专业诊断。
- 不尝试绕过 DeepSeek、OpenAI 等模型供应商自身的使用政策。

## 4. 用户场景

### 4.1 学习观察

- “他最近数学为什么总要听两遍？”
- “从这周记录看，接下来优先练数量还是分类？”
- “今天三个活动应该怎么在生活里延伸？”

### 4.2 内容共创

- “用恐龙和挖掘机编一个三分钟睡前故事。”
- “设计一个不看屏幕的英语小游戏。”
- “把今天的数学目标变成吃水果时可以玩的活动。”

### 4.3 家长研究与决策

- “三岁半有必要开始自然拼读吗？”
- “比较两种亲子阅读方式的优缺点。”
- “给我一份下周家庭启蒙安排，保持每天十分钟以内。”

## 5. 功能范围

### 5.1 家长 AI 助手

位于家长中心，长按家长门后才可访问。

- 支持连续多轮对话。
- 支持 DeepSeek 与 GPT 供应商切换。
- 显示供应商、模型名、是否已配置。
- 支持“携带近期学习摘要”开关。
- 提供四个快捷问题：今日延伸、近期观察、下周建议、生成亲子游戏。
- 浏览器最多保留最近 10 轮对话（20 条消息），每次请求只携带最近 10 条消息，避免无限增加成本和上下文污染。
- 回答以 Markdown 风格纯文本呈现，不执行模型返回的 HTML 或脚本。
- 对话保存在当前浏览器，清空试玩数据时同步删除。

### 5.2 模型切换

统一供应商注册表：

| 供应商 | P0 默认模型 | 接口 | 状态 |
| --- | --- | --- | --- |
| DeepSeek | `deepseek-v4-flash` | Chat Completions | 已接入并验证 |
| OpenAI | `gpt-5.4-mini` | Responses API | 接口预留，配置 Key 后启用 |

模型清单由服务端返回，前端不能提交任意模型名，避免意外调用高成本或不存在的模型。

环境变量：

```dotenv
AI_DEFAULT_PROVIDER=deepseek

DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com

OPENAI_API_KEY=
OPENAI_MODEL=gpt-5.4-mini
OPENAI_BASE_URL=https://api.openai.com/v1
```

### 5.3 学习上下文

发送给 AI 的上下文只包含：

- 年龄段：三岁左右。
- 兴趣标签，不发送昵称。
- 最近最多 12 个活动的学科、技能、玩法、完成情况、尝试次数、提示等级、语音重播次数和大致时长。
- 今日计划的活动 ID、技能与标题。

家长关闭上下文开关后，只发送聊天内容。

### 5.4 内容边界

家长助手不再受“只能从审核题库中选择内容”的限制，可以生成故事、比较观点、设计亲子活动并讨论教育方法。系统提示只要求：

- 明确区分事实、推测和建议。
- 不根据少量活动记录做诊断或给孩子贴标签。
- 涉及高风险问题时建议咨询适当专业人士。
- 尊重家长的判断，不用居高临下的语气。

不额外接入本地敏感词表或审核模型。供应商拒答、限流和政策约束属于上游能力，产品不能也不应承诺关闭。

### 5.5 试玩数据重置

当前版本没有服务器数据库，进度存在浏览器 `localStorage`。重置范围：

- 学习结果 `cheese-results-v2`
- 所有 `cheese-plan-*` 每日计划
- AI 对话 `cheese-ai-chat-v1`
- AI 供应商偏好 `cheese-ai-provider-v1`

默认保留昵称、兴趣和声音设置，避免重置后重复配置。家长中心提供二次确认按钮；同时给开发者提供浏览器控制台命令。

## 6. UI/UX

### 6.1 AI 助手卡片

- 在家长中心占满一整行，和原有每日编排卡区分。
- 顶部依次为“AI 家庭助手”、供应商切换、学习上下文开关和连接状态。
- 对话区在手机上高度约 360 px、平板约 440 px，内部滚动。
- 家长消息右对齐，AI 消息左对齐，使用低刺激绿色和米白色。
- 输入框支持 500 字；发送中禁用重复提交。
- 未配置 GPT 时仍显示选项，但明确标注“待配置”，不吞掉用户输入。

### 6.2 快捷问题

- “解读近期表现”
- “延伸今天活动”
- “安排下周重点”
- “生成亲子游戏”

点击后填入输入框，不自动发送，给家长修改机会。

### 6.3 重置入口

- 放在家长中心“体验控制”卡片底部。
- 第一次点击显示确认状态，第二次点击才执行。
- 重置后显示“试玩进度已清空”，立即刷新首页完成数和观察记录。

## 7. API 设计

### 7.1 `GET /api/ai-assistant`

返回可选供应商与配置状态，不返回任何 Key。

```json
{
  "providers": [
    { "id": "deepseek", "label": "DeepSeek", "model": "deepseek-v4-flash", "configured": true },
    { "id": "openai", "label": "GPT", "model": "gpt-5.4-mini", "configured": false }
  ],
  "defaultProvider": "deepseek"
}
```

### 7.2 `POST /api/ai-assistant`

```json
{
  "provider": "deepseek",
  "messages": [{ "role": "user", "content": "今天适合怎么延伸？" }],
  "context": {
    "interests": ["dinosaurs", "vehicles"],
    "recentResults": [],
    "todayActivities": []
  },
  "clientId": "anonymous_device_id"
}
```

响应：

```json
{
  "reply": "……",
  "provider": "deepseek",
  "model": "deepseek-v4-flash"
}
```

### 7.3 统一适配层

- DeepSeek：`POST /chat/completions`
- OpenAI：`POST /responses`，`store: false`
- 统一转换成 `{ reply, provider, model }`
- 单次超时 25 秒，每个匿名设备每日最多 40 次、每个网络入口每日最多 120 次问答
- 日志只记录供应商、耗时、状态码和错误类型，不记录聊天正文或 Key

## 8. 隐私与成本

- API Key 只存在服务器 `.env`。
- OpenAI 请求设置 `store: false`。
- 客户端对话仅本机保存。
- 输入最多 500 字，历史最多 10 轮，回答最多约 1200 字。
- DeepSeek 作为默认低成本模型；GPT 配置后由家长主动切换。
- 达到限额时保留输入并明确提示，不假装已经回答。

## 9. 成功指标

- AI 助手请求成功率 ≥ 98%。
- 首次回答时间 P95 ≤ 15 秒。
- 模型切换成功率 ≥ 99%。
- 家长侧 AI 功能周使用率 ≥ 30%。
- 快捷问题使用占 AI 请求的 25%–60%。
- 重置操作二次确认覆盖率 100%。
- 不发生 API Key 下发前端或写入 Git 的事件。

## 10. 验收标准

- DeepSeek 配置存在时可完成真实多轮问答。
- GPT 未配置时显示“待配置”，请求返回明确错误。
- 配置 OpenAI Key 后无需改前端即可启用 GPT。
- 开启上下文时，AI 能引用近期活动；关闭后请求中不包含学习记录。
- 家长助手不出现在儿童页面和活动覆盖层。
- 模型返回的 HTML 只能作为文本显示。
- 重置后完成数、宝箱、今日观察和 AI 对话立即清空。
- 刷新页面后重置结果保持为空。
- Docker、Nginx、无 Key 回退和现有 45 个活动全部继续工作。
