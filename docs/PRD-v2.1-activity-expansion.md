# 小满的小世界 V2.1 迭代 PRD

> 主题：活动扩容、互动玩法升级与真正可持续的三岁启蒙体验
> 状态：M1 已实现（2026-08-21）
> 目标用户：三岁左右儿童与家庭陪伴者
> 目标终端：手机、平板优先，桌面兼容
> 产品定位：家庭自用、无广告、低刺激、可长期使用的语数英启蒙产品

## 1. 执行摘要

当前版本已经具备完整产品闭环：每天中文、数学、英语各一个任务，支持语音、温和反馈、奖励、家长中心、DeepSeek 编排、PWA 和 Docker 部署。

下一阶段不应只机械增加选择题，而应同时完成三项升级：

1. 活动库从 18 个扩展到 72 个，中文、数学、英语各 24 个。
2. 互动方式从以“三选一”为主，扩展为点击、拖拽、分类、排序、场景放置、点数、故事选择、开放探索等至少 8 种模板。
3. 从“按日期换题”升级为基于接触记录的复习与难度编排，让孩子在熟悉、巩固和新内容之间自然循环。

每天仍只展示三个核心任务，总使用时间保持在 6–12 分钟。新增内容用于降低重复、支持长期使用，不用于拉长屏幕时间。

### 1.1 M1 实现记录

- 活动总量已从 18 个增加到 45 个，中文、数学、英语各 15 个。
- 七种 P0 互动模板已经进入统一运行时，并保留原有大卡片点选玩法。
- 新活动已补齐技能 ID、难度、月龄、变量数量和交互结构；每次进入会重排素材位置，避免记忆固定答案位置。
- 完成记录已增加模板、首次正确、提示等级、语音重播、完成与中途退出字段。
- 每日编排已保证三学科各一个，并避免同日主要交互模板重复；DeepSeek 仍只能选择审核题库 ID。
- 手机与平板已增加点数、拖拽、点击后放置的双操作路径；Docker Compose 与 Nginx 一键部署已补齐。
- M2 的剩余 27 个活动、开放探索和节奏/描画模板仍按本 PRD 后续推进。

## 2. 当前版本诊断

### 2.1 已有优势

- 每天三个任务，信息密度适合低龄儿童。
- 中文、数学、英语结构清晰，家长容易理解。
- 恐龙、交通工具、工程机械和太空作为默认兴趣主题，符合当前家庭偏好。
- 没有排行榜、连续打卡惩罚、抽卡和强刺激反馈。
- DeepSeek 只从人工审核内容中选题，不直接向儿童生成题目。
- 错误反馈温和，第二次失败后才提供明显支架。
- 已有离屏任务，具备从屏幕迁移到真实生活的基础。

### 2.2 主要问题

| 问题 | 当前表现 | 用户影响 |
| --- | --- | --- |
| 内容池偏小 | 每科仅 6 个活动 | 高频使用约两周后会明显重复 |
| 交互同质化 | 绝大多数活动都是点击三个选项之一 | 换了题目但操作体验没有变化 |
| 记录维度不足 | 主要记录完成、尝试次数和时长 | 无法区分“独立掌握”“提示后完成”“只是重复点选” |
| 缺少复习模型 | 按日期和兴趣选题 | 难以稳定实现间隔复习和由易到难 |
| 表达与创造偏少 | 以识别正确答案为主 | 口语表达、故事理解、想象和开放探索不足 |
| 数学覆盖不完整 | 有点数、形状、长短、分类、规律 | 缺少多少比较、空间方位、对应、简单增减和非标准测量 |
| 英语输入形式单一 | 单词和简单指令听辨为主 | 缺少短句情境、节奏歌谣、故事理解和重复迁移 |
| 多设备记录割裂 | 记录仅保存在浏览器 | 手机和平板之间无法共享进度 |
| 美术资产仍偏工具化 | 大量使用通用线性图标 | 角色感、故事感和儿童记忆点仍可增强 |

## 4. 产品目标与非目标

### 4.1 V2.1 目标

- 活动总量达到 72 个，每科 24 个。
- 同一天三个任务不能使用同一种主要交互模板。
- 连续使用四周时，精确活动重复率低于 20%。
- 每个核心能力至少有两种不同主题或交互方式。
- 形成“新接触—练习—熟悉—复习”的内部掌握状态。
- 增加故事理解、表达、空间方位和开放探索内容。
- 保持 6–12 分钟自然结束，不以提高使用时长作为目标。
- 手机和平板的触控、横竖屏和离线体验稳定。

### 4.2 非目标

- 不做小学化的拼音、汉字默写、算式和英语拼写训练。
- 不做通用 AI 陪聊，不允许模型直接面对儿童开放生成。
- 不使用麦克风进行强制语音评分；低龄口音识别误差会破坏体验。
- 不引入排行榜、连续签到惩罚、随机抽奖、虚拟币商城和广告。
- 不用性别限制活动。男孩兴趣只作为默认偏好，仍保留动物、自然、情绪、艺术和生活主题。
- 不用长视频作为主要教学载体。

## 5. 目标体验结构

### 5.1 每日结构

1. **三个核心任务**：中文、数学、英语各一个，每个 2–3 分钟。
2. **今日自由玩**：完成任意一个核心任务后可进入，开放探索 2–5 分钟，可随时退出，不计输赢。
3. **离开屏幕的小挑战**：当天只提供一个，30–90 秒即可完成。
4. **自然收尾**：三个核心任务完成后，豆豆龙明确说“今天玩好啦”，首页不再制造新的紧迫入口。

### 5.2 每周主题

用一个轻故事把一周内容串起来，但不要求连续打卡：

- 恐龙救援队
- 工程车造桥
- 太空补给站
- 城市交通日
- 森林观察员
- 动物照顾站
- 海洋小潜艇
- 家庭生活小帮手

主题只负责情境和视觉，不改变学习目标。未选择某一主题的孩子仍可正常获得完整能力覆盖。

## 6. 活动运行时 V2

### 6.1 活动模板

| 模板 | 说明 | 示例 | 优先级 |
| --- | --- | --- | --- |
| `tap_choose` | 点击 2–3 个大选项 | 听到 car 后点汽车 | 已有，保留 |
| `tap_count` | 每点一个物体就移动/变亮并播报数量 | 一颗一颗装 4 块石头 | P0 |
| `drag_match` | 把对象拖到对应对象 | 动物和住处分组 | P0 |
| `drag_sort` | 把 4–6 个对象分到两个篮子 | 大车/小车分类 | P0 |
| `place_in_scene` | 把对象放到上、下、里、外等位置 | 把汽车停在桥下面 | P0 |
| `sequence_3` | 拖动三张图排列生活或故事顺序 | 起床、刷牙、吃早餐 | P0 |
| `pattern_extend` | 拖入下一个图形、颜色或声音 | 红蓝红蓝 | P0 |
| `story_choice` | 听 2–3 句微故事后选择下一步或关键物品 | 恐龙口渴了，需要什么 | P0 |
| `rhythm_repeat` | 听节奏后按大按钮复现 | 拍—拍—停 | P1 |
| `trace_path` | 沿宽路径描画，不要求精细笔画 | 帮火箭沿轨道回家 | P1 |
| `open_play` | 无对错的可操作场景 | 用形状搭火箭、给车装货 | P1 |
| `physical_mission` | 屏幕给动作指令，孩子离开屏幕完成 | 找两个圆形物品、跳两下 | P1 |

### 6.2 统一交互规则

- 每屏只要求一个主要动作。
- 选择数量最多三个；拖拽对象最多六个。
- 可点击区域最小 56×56 px，主要选择卡建议不小于 88×88 px。
- 指令必须可通过语音完成理解，文字只给家长辅助。
- 中文屏幕主指令建议不超过 18 个汉字。
- 首次错误：不给红叉和刺耳音效，只给语义提示。
- 第二次错误：高亮关键特征或正确区域，不直接自动作答。
- 30 秒无操作：豆豆龙给一次轻提示；再无操作不连续打扰。
- 所有动画均可在“减少动画”模式下替换为淡入或静态状态。
- 不只靠颜色传递正确、错误和分类信息。
- 任何任务都允许退出，退出不显示失败。

### 6.3 内容数据模型新增字段

```ts
type MasteryLevel = "new" | "exploring" | "familiar" | "review";

interface ActivityV2 {
  id: string;
  domain: "chinese" | "math" | "english";
  skillId: string;
  template: ActivityTemplate;
  difficulty: 1 | 2 | 3;
  interests: InterestKey[];
  ageBand: "30-36m" | "36-42m" | "42-48m";
  instruction: string;
  spokenInstruction: string;
  assets: ActivityAssets;
  variants: ActivityVariant[];
  parentTip: string;
  offlineMission?: OfflineMission;
  contentReviewVersion: number;
}
```

每个活动至少准备两个变量版本，例如对象位置、颜色、数量或干扰项变化，防止孩子只记住界面位置。

## 8. 个性化与复习编排

### 8.1 掌握状态

掌握状态只供系统和家长参考，不展示给孩子：

- `new`：从未接触。
- `exploring`：接触过，但需要提示或中途退出。
- `familiar`：至少两次独立完成，且跨不同日期。
- `review`：曾经熟悉，但达到复习间隔。

### 8.2 每日选择规则

先由确定性规则生成合格候选，再允许 DeepSeek 在候选中排序：

1. 中文、数学、英语各一个。
2. 一天三个任务的主要交互模板不得重复。
3. 至少一个任务匹配孩子的高优先兴趣。
4. 一天最多一个难度 3 活动。
5. 精确活动默认七天内不重复；提示后仍困难的活动可在 1–3 天内换主题复现同一技能。
6. 推荐比例：50% 熟悉内容、30% 到期复习、20% 新内容；每日三个任务允许按周平衡。
7. 同一技能建议在第 1、3、7 天通过不同主题或模板再接触。
8. 孩子连续两次退出某技能时，下一次自动降一级支架，不继续加难。
9. DeepSeek 仍只能输出活动 ID、排序理由和家长建议，不能修改答案、语音和儿童文案。
10. AI 失败时使用相同规则的本地编排，体验不降级。

### 8.3 需要新增的记录

```ts
interface ActivityAttemptV2 {
  activityId: string;
  variantId: string;

  startedAt: string;
  durationSeconds: number;

  audioReplayCount: number;
```

不记录孩子语音、照片、自由文本和精确身份信息。

## 9. UI/UX 改造要求

### 9.1 孩子端

- 首页保持一个主按钮和三张学科卡，不增加复杂菜单。
- 新增“今天自由玩”卡片，与核心任务视觉区分，不显示完成压力。
- 每周主题用一张连续变化的场景图表现，不做线性闯关地图。
- 豆豆龙承担指令复述、轻提示和自然收尾，不连续弹出对话。
- 奖励从“累计数量”升级为探险图鉴：每个收藏对应真实接触过的主题或技能。
- 正确反馈最长 1.5 秒，不能阻塞孩子继续操作。
- 错误状态不使用大面积红色、抖动、哭脸和失败音效。
- 拖拽目标区必须明显大于拖拽物，允许接近目标时吸附。

### 9.2 家长端

- 增加本周概览：接触天数、每科活动数、独立完成率、常用提示等级。
- 用“最近喜欢”“正在熟悉”“可以生活中再玩”替代排名和分数。
- 展示具体建议，例如“已经能稳定分辨 1–3，可以在分水果时继续一一对应”。
- 支持手动隐藏某个主题或活动，但不能直接跳到超龄难度。
- 支持查看今日 AI 为什么选择这三个活动。
- 增加数据导出与一键删除。

### 9.3 多设备同步

当前本地存储会导致手机和平板进度分离。建议作为 V2.1 P1：

- 家长中心生成六位家庭配对码，新设备一次性输入后加入家庭。
- 服务端使用匿名 `familyId`，不要求手机号、邮箱和真实姓名。
- 使用 SQLite 持久化档案、活动记录、计划和收藏，Docker 映射独立数据卷。
- 默认仍允许“仅本机模式”。
- DeepSeek 请求继续剔除昵称、配对码和家庭标识。
- 配对码短时有效；家长可查看并移除已配对设备。

## 10. 美术与音频资产

### 10.1 美术系统

- 保持柔和纸感、低饱和暖色和圆润轮廓。
- 建立豆豆龙的 8 个基础动作：挥手、倾听、思考、提示、庆祝、休息、行走、抱物。
- 建立 8 个主题场景包，每个包含背景、3–5 个可交互对象和 2 个环境动画。
- 学习对象优先使用原创插画，不再以通用图标作为主视觉。
- 同一对象必须跨活动保持形状和颜色识别一致。

### 10.2 音频系统

- 浏览器 TTS 保留为离线或缺失音频时的兜底。
- 核心活动逐步替换为真人或统一角色音色录音。
- 中文语速约 0.8–0.9 倍自然语速；英文单词第一次正常、第二次略慢，不做夸张拆音。
- 环境音低于语音至少 8 dB，语音播放时自动压低背景声。
- 单个反馈音不超过 1.2 秒，避免连续叠加。

## 11. 埋点与成功指标

### 11.1 产品健康指标

- 活动启动成功率 ≥ 99.5%。
- 活动完成率 ≥ 75%。
- 中途退出率 ≤ 20%，但退出不作为孩子失败。
- 90% 的单次使用时长落在 6–12 分钟。
- 精确活动七日重复率 ≤ 20%。
- 三个任务使用不同交互模板的达成率 = 100%。
- DeepSeek 不可用时本地计划回退成功率 = 100%。
- 页面横向溢出率 = 0，核心任务支持 360 px 宽手机。

### 11.2 学习体验观察指标

- 独立完成率按技能趋势上升，而不是追求全局高分。
- 同一技能第二次跨日接触时，平均提示等级下降。
- “再听一次”的使用能定位音频或指令不清，不把它视为错误。
- 家长每周至少能获得一条具体、可在线下执行的建议。
- 开放探索的退出自然，不出现强制下一关入口。

### 11.3 不优化的指标

- 不以日活、连续天数、单次停留时长和点击次数最大化为目标。
- 不设计让孩子为了奖励反复刷简单任务的机制。

## 12. 内容与技术验收标准

每个新活动上线前必须通过以下检查：

### 内容审核

- 学习目标单一、明确，适合 30–48 个月儿童。
- 不要求识字才能完成。
- 不包含危险模仿、恐吓、暴力、购买暗示或性别刻板评价。
- 男孩兴趣主题不等于只出现车和恐龙，内容池同时覆盖情绪、照顾、自然和艺术。
- 正确答案唯一；开放活动必须明确标记为无对错。
- 英文发音、用词和图片意义经过人工复核。

### 交互审核

- 360×780 手机、390×844 手机、768×1024 平板、820×1180 平板均可用。
- 横屏低高度场景不会遮挡主要选项。
- 触控目标满足最小尺寸，拖拽有吸附和撤销。
- 语音关闭后，成人仍可通过文字理解任务。
- 减少动画模式下逻辑完整。
- iOS Safari、Android Chrome 和主流平板浏览器完成真机抽测。

### 工程审核

- 活动数据通过 schema 校验和答案一致性检查。
- 每个活动至少有两个变量版本。
- AI 不能返回题库外 ID。
- 无网络、无 DeepSeek Key、DeepSeek 超时三种情况可正常完成当天任务。
- PWA 缓存至少覆盖当天计划及所需图片、音频。
- 自动化测试覆盖每种模板的成功、一次错误、二次提示、退出和恢复。

## 14. 优先级结论

### P0：必须先做

1. 七种新互动模板。
2. M1 的 27 个新活动。
3. 活动变量版本和更完整的尝试记录。
4. 同日模板去重与本地确定性编排。
5. 手机/平板触控与离线资源回归。

### P1：紧随其后

1. 活动扩展到 72 个。
2. 故事、节奏、动作和开放探索。
3. 掌握状态与间隔复习。
4. 家长周报与选题解释。
5. 手机和平板家庭同步。

### P2：验证后再做

1. 多个开放探索场景。
2. 真人角色配音全覆盖。
3. 家长自定义一周主题。
4. 可打印的线下任务卡。

## 15. 关键产品决策

- **内容多，不等于每天做得多。** 题库扩容只用于降低重复和支持个性化。
- **先增加玩法，再批量加题。** 否则 72 个活动仍会像 72 道换皮选择题。
- **三岁中文以听说和阅读兴趣为主。** 不把识字量、拼音和笔画作为目标。
- **英语先理解再开口。** 不强制跟读，不做低龄语音评分。
- **数学来自操作和生活。** 点数、分类、空间和比较优先于认数字和算式。
- **AI 是编排器，不是老师。** 所有儿童可见内容和答案必须来自人工审核题库。
- **奖励服务于回忆，不服务于成瘾。** 图鉴对应真实探索内容，不使用随机奖励。
- **兴趣可偏向但不设限。** 默认强化恐龙、车辆、工程和太空，同时主动保留情绪、照顾、动物、自然和艺术内容。
